{# ──────────────────────────────────────────────────────────────────────────── Single source of truth for SentinelAI's palette, typography and shared component styles. Included by every page that owns a : base.html (all sidebar pages), login.html and home.html (both standalone). Nothing below is page-specific, so a colour only ever has to change here. HOW IT WORKS ------------ Every colour is a CSS custom property holding a bare "R G B" triple, which the Tailwind config below wraps as `rgb(var(--x) / )`. Keeping the channels unwrapped is what lets the opacity modifiers already scattered through the templates (bg-sentinel-800/60, border-blue-900/30, ...) keep working after the repaint. Four Tailwind scales are re-pointed at those variables, so the whole app repaints without touching a single template: slate / sentinel -> neutral charcoal ramp (structure) blue -> burnt-orange ember ramp (accent, links, focus, logo) cyan -> warm gold ramp (secondary accent) purple -> plum ramp (the "AI output" marker) DELIBERATELY NOT REBRANDED: red / orange / amber / green. Those carry meaning -- CRITICAL / HIGH / MEDIUM severity and success -- so their hues stay put, and in the dark theme their values are byte-for-byte Tailwind's own. Only their light text steps (200/300/400) are variable-backed, so the light theme can darken them enough to be legible on a pale chip without changing what any of them mean. LOW severity is drawn from the slate ramp and therefore stays grey in every theme. NEUTRAL RAMP ORDERING: in the dark themes the ramp runs light (n-50) to dark (n-950), exactly like Tailwind's own. In the light theme it is REVERSED, so that `text-slate-400` still means "muted text" and `bg-sentinel-950` still means "page background". Read the ramp as distance from the page background, not as absolute lightness. ──────────────────────────────────────────────────────────────────────── #} {# Applied before anything paints, so a non-default theme never flashes the default one first. Kept inline and dependency-free for that reason: an external file is a second round trip during which the wrong theme shows. #}
